# The Unburdening (Bhāravataraṇa)

A personal reading copy of the book as a small website: the story in eleven parts, one page per part with every people
that tells it and its lines, the chapters, the sources, the themes, the figures, the research read section by section,
and the wall.

The front door is `index.html`. GitHub Pages serves the root of `main`. Everything runs in the browser; Google Fonts is
the only outside call.

This repository is a generated export and nothing in it is edited by hand. The source workspace is private; the site is
rebuilt there with `tools/build_site.py` and published with `tools/publish.py`.

`robots.txt` asks crawlers not to index this copy; the pages are still reachable by anyone with the address.
